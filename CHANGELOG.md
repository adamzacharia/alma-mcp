# Changelog

## 0.1.0 (2026-11-02)

First public release.

- `alma-corpus-mcp`: 10 tools over methods cards from 3,537 ALMA papers (search, cards, recipes, parameter census,
  software usage with technique-specific ranking, comparisons, 38 reviewed technique skills as prompts and
  resources). Data bundle `2026.11.02` (public variant) attached to the GitHub release.
- `alma-analysis-mcp`: 20 tested analysis tools (dust and gas masses, SED fits, line luminosities, rotational
  diagrams, moment maps, Keplerian masks, dynamical and virial masses, Toomre Q, uv-plane fitting, imaging checks),
  each stating its formula and convention. File access confined to `ALMA_MCP_WORKDIR`.
